# SQL-Data-Analysis-using-SQLite-and-Python
This project shows how SQL can be used with Python in Jupyter Notebook for basic data analysis. Using SQLite, I created a small sales database and performed SQL queries to analyze and visualize the data.

## Tools Used
- Python
- SQLite
- Pandas
- Matplotlib
- Jupyter Notebook

## Project Tasks
- Created a SQLite database
- Inserted sale data into a table
- Performed basic SQL queries
- Filtered data using WHERE, BETWEEN and CASE statements
- Visualized SQL data using Pandas and Matplotlib

## SQL Concepts Used
- SELECT
- WHERE
- AND
- BETWEEN
- CASE
- GROUP BY
- Aggregation Functions

## Key Insights
- Electronics products generated the highest revenue.
- Mumbai had multiple customer orders.
- Expensive products mainly belonged to the Electronics category.
- SQL helped in filtering and analyzing customer purchase data efficiently.

## Skills Demonstrated
- SQL Query Writing
- SQLite Database Handling
- Python and SQL Integration
- Data Analysis
- Data Visualization

This project helped me understand how SQL and Python work together for data analysis. It also improved my understanding of database operations, querying, and visualization in Jupyter Notebook.
